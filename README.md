# TDZ Marketing

Site profissional, moderno e responsivo para a TDZ Marketing, especializada em divulgação em grupos do WhatsApp.

## Recursos

- Design dark e mobile-first
- Planos com mensagens automáticas específicas
- Botões de contato pelo WhatsApp
- Menu responsivo
- Seção preparada para feedbacks reais
- SEO básico

## Alterar o WhatsApp

No topo do arquivo `script.js`, altere:

```js
const WHATSAPP_NUMBER = '13998016977';
```

Use somente números com DDD.

## Adicionar feedbacks

No arquivo `index.html`, procure por `[ADICIONAR PRINT DE FEEDBACK AQUI]` e substitua cada placeholder por uma imagem real de cliente. Antes de publicar, oculte dados pessoais quando necessário.

## Publicação

O projeto é estático e pode ser publicado no GitHub Pages, Netlify, Vercel ou em qualquer hospedagem de sites.
